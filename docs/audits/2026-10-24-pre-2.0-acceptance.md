# Pre-2.0 acceptance — every human check, and what replaced it

**Date:** 2026-10-24
**Scope:** the acceptance surface that stood between the harness and a pre-2.0 close.
**Rule applied:** a check is replaced only when an agent (or a machine check) can
observe **the same quantity**. Where the quantity is human cognition, the *check* is
replaced by recorded instrumentation or by a signed scope decision — never by a number
that measures something else.

## 1. Substitutions made

| # | Human check | Replacement | Same quantity? | Artifact |
|---|---|---|---|---|
| 1 | "A second person reviewed the oracle" | Model-independent review from a different model family and harness, on a pinned commit, own verdict, verbatim output committed | **No — weaker, and labelled.** A model is not a person; it cannot catch what only human judgement would | [oracle review](2026-10-24-gb01-oracle-review.md) §0, `docs/audits/evidence/2026-10-24-codex-gb01-oracle-review.txt` |
| 2 | "A human re-checked the 45 outcomes" | `benchmark/evidence/rescore-collection.mjs` re-derives every re-derivable row from retained evidence: 40 exact-content objectives by sha256, 15 answer assertions, 5 admissibility strings | **Yes for arithmetic and objective state.** No for "a human read the reports" | `benchmark/evidence/eval-runs/collection-2026-10-24-final/RESCORE.md` |
| 3 | "A reviewer confirms the defects are fixed" | 26-case parity table including must-stay-accepted rows; the two real navigation runs that a naive detector failed are pinned as tests | **Yes for the fixed cases, plus over-correction cases** | `tests/evals/oracle-parity.vitest.ts` |
| 4 | "A human signs off the waiver" | Validator requires the cited waiver file to exist **and to name the signer**; a bare flag is rejected | **Yes for "a signature exists".** No for "the signer understood it" | `benchmark/evidence/gate-b-scoring-record.mjs` `checkWaiverCitation` |
| 5 | "A human decides the gate is closed" | `CLOSED-WITH-WAIVER` is computed from the record: complete, independent, 0 missing, 0 partial, every non-met entry signed-waived. | 6 | "A human tallies which rows are met" | Record validated + summarized mechanically; an aggregate over a partial record is refused | **Yes** | same file |

## 2. What an agent still cannot do

**M-1 — operator active review minutes.** The quantity is time a person spends reading
and deciding. No agent can observe it, and substituting agent runtime measures a
different thing by orders of magnitude — the exact inversion §12.3 exists to prevent.
It is **signed-waived**, not filled.

The honest alternatives, in order of cost:

1. **Instrument it (best).** If the operator reviews through the Inspector or TUI, the
   system can timestamp review sessions itself — same quantity, no stopwatch, no
   self-report. Not implemented; no review session was instrumented, so n = 0 still.
2. **Route A (~3 h, `$0`).** One person with a stopwatch, scored by code that already
   exists. Converts `waived` → `met`.
3. **Waive (chosen).** Recorded, signed, cited, and mechanically checked.

**Gate E independence.** Model-independent review is accepted as a weaker class. It is
not human independence and no agent can manufacture that; the label travels with every
citation.

**Gate F / Q13 — release.** Decomposed clause by clause in
[the enumeration](2026-10-24-gate-f-q13-enumeration.md). Eight of its eleven clauses are
now machine-observed: the five negatives PRD-R082 names (missing clearance, expired
clearance, absent approval, mismatched artifact, technical FAIL), plus artifact binding,
self-cleared restrictions, and backdated approval. The record validates to `HOLD` on
three facts — technical `partial`, no clearance, no maintainer decision.

Two clauses are not replaceable and were not replaced:

- **Independent security publication clearance.** Independence means the clearer is not
  the author. A model reviewing model work is `model-independent` — the same weaker class
  already labelled throughout Gate B — not independent security clearance.
- **The authorized maintainer's decision.** This is an authority, not a measurement. A
  model recorded in that field is rejected outright (`signerClass: "model"`), which
  mechanises "never fill another party's signature".

Unlike Gate B, Gate F has **no waiver path**. Gate B waived GB-11 because the quantity
(review minutes) was unmeasurable and a waiver honestly disposed of the *measurement*.
Q13's requirement *is* the clearance and the decision, so a waiver would delete the
requirement rather than substitute for it.

## 3. Closure state

| Item | State |
|---|---|
| Gate B requirements | 14/14 dispositioned — **13 met, 1 waived** |
| Gate B outcome | `CLOSED-WITH-WAIVER` (validator-computed) |
| Independence class | `model-independent` — never `independent` unqualified |
| Required citation phrase | "Accepted baseline with a waived operator-attention dimension" |
| Gate E | Independence absent; weaker class accepted |
| Gate F / Q13 | HOLD — computed (3 recorded facts); no waiver path |
| M-1 attention | `null`; n = 0; waived and signed |

## 4. What this does not claim

- It does not make GB-11 `met`, and it reports no attention figure.
- It does not establish human independence, satisfy PRE-R017/PRE-R031 (both count human
  observations), or clear Gate E.
- It does not make the baseline vendor-priced: every dollar figure is a proxy rate.
- It does not retire the measurement. Route A or instrumentation still converts `waived`
  → `met`, and the waiver must be repeated until then.
- It does not clear Gate F/Q13, obtain a security clearance, or record a maintainer
  decision. The release record validates to `HOLD` on purpose.
