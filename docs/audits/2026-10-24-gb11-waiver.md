# GB-11 waiver — operator attention not measured, accepted as a gap

**Date:** 2026-10-24
**Decision requested of the operator. This document does not sign itself.**
**Effect if signed: GB-11 moves `missing` → `waived`. Gate B stays HOLD.**

## 1. What is being waived

PRD §12.1 / §7 require `operatorActiveReviewMinutes / independentlyVerifiedSuccesses`
reported alongside cost, latency and verified outcomes.

**No such measurement exists, and none was attempted.** n = 0.

## 2. Why it cannot be produced by the agent work

M-1 measures human cognition — time spent reading evidence, comparing it, and deciding.
An agent cannot observe that. Four of the five attention measures *were* made
agent-derivable (M-2..M-5, see
[agent measures](2026-10-24-operator-attention-agent-measures.md)); M-1 is the one that
is definitionally human.

The substitute that would be available — reporting agent runtime as review time — is a
**different quantity**, off by orders of magnitude, and would invert §12.3's purpose
(separating human attention from machine time so speed cannot masquerade as quality).
It is not used.

## 3. What a waiver records, and what it does not

| A waiver records | A waiver does not record |
|---|---|
| The operator has seen that M-1 is unmeasured | That operator attention is acceptable |
| The gap is known, dated and attributed | That the gap is zero |
| Gate B proceeds with this requirement **unmet** | That GB-11 is `met` |
| A weaker claim than a measured baseline | That Gate F/Q13 may publish |

This follows the existing discipline already applied to Gate E:
*"An operator waiver records author-only testing as a weaker labeled claim; it does not
create independence."* The same logic applies here — a waiver records acceptance of a
gap, not the closure of it.

## 4. What the baseline can be cited for under this waiver

**Permitted:**
- "45 runs, 36 independently verified, `$0.080520` per verified success, latency
  measured per case, all ten strata exercised."
- "Operator attention is **not measured**; M-1 is `null`."
- "Gate B is HOLD pending GB-11 measurement and GB-14 signature."

**Not permitted:**
- Any statement about operator effort, review speed, or supervision cost.
- Any comparison between workflows on attention grounds.
- Any claim that Gate B is met, cleared or signed.
- Any implication that attention cost is zero because no number was reported.

## 5. Consequences carried forward

1. **GB-11 remains `waived`, not `met`.** Any future baseline claim must repeat the
   waiver or supply the measurement.
2. **GB-14 cannot be signed as a full baseline acceptance.** It may be signed only as
   acceptance *of a baseline with a waived attention dimension*, and that phrase must
   appear wherever the acceptance is cited.
3. **PRE-R031 stays open.** Reviewer time, sampling quality and missed-risk rates were
   never in scope here.
4. **M-1's protocol is unaffected.** `docs/audits/2026-10-24-gb11-instructions.md` stays
   valid for whenever someone does run it; the waiver is a deferral, not a retirement.

## 6. The cheaper alternative, restated

Route A in the instructions: **~3 hours, `$0`, one person with a stopwatch**, scored by
code that already exists. That converts `waived` into `met` and removes the last
measurement-shaped blocker on Gate B.

The waiver exists because that person is not available. It should not exist because the
work is expensive — it is not.
