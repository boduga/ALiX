**Determinism check:** two consecutive runs produced identical verdicts
(`diff` of PASS/FAIL lines empty). A third observation showed one flake in
`behavioral.block-replacement` during `--synthetic` mode; it passed 2/2 on
immediate re-run and 3/3 without synthetic. That case uses the `delegate`
driver, which spawns a real subagent child process — the flake is in the
delegate transport, not in any measurement code (which is not on that path).
**Recorded as an observation, not dismissed.**

The two `--synthetic` fixtures (`synthetic-false-success`,
`synthetic-false-failure`) intentionally FAIL: they are evaluator self-tests
proving a dishonest status report is detected. A passing synthetic fixture would
mean the evaluator is broken.

## 3. The dominant Gate B blocker is cost, not code

**Every stratum lacks measured cost.** Two independent reasons:

1. Recorded Gate 7 summaries carry no usage or pricing data — they predate the
   P0-D2 projection. Tokens are now derivable from `model.usage` events
   (proven: 46 982 / 1 585 in `f8b-final`), but **no pricing record is
   correlated to a run id**, so `observedCostUsd` must remain `null`.
2. Scripted-provider evals have no billable usage at all.

This is a **data and correlation gap**, not a missing feature. Per the approved
rule, `null` stays `null`; nothing is reported as zero.

**What unblocked it (F1-E, since completed):** two provider defects meant no
streaming run ever carried usage at all — `stream_options.include_usage` was
never sent, and o-series models rejected `max_tokens`. With those fixed, a real
run reproduced its cost three ways ($0.108968). See
`harness-f1e-qualified.md`. Cost correlation is now proven **mechanically**; what
remains is running it across the remaining strata, which requires real-model
runs rather than deterministic ones.

## 4. Harness readiness verdict

**NOT ready for ablation comparisons — but the two original blockers are gone.**

The coverage blocker is closed: strata 2, 4, 5 and 10 now have deterministic case
coverage, so an ablation is no longer measuring "the easiest third of the work".
The cost-mechanics blocker is closed by F1-E.

What still blocks a defensible ablation:

- **Cost is measured in 1 of 10 strata.** One 3-invocation run proves the
  mechanism, not a baseline. The other strata are deterministic runs with no
  billable call, so their cost is genuinely `null`.
- **Stratum 9's suite has not run to completion.** Local CPU inference on this
  4-core box costs minutes per case; the inference path is proven but the
  stratum's full suite evidence is not collected.
- **D4-04 is bounded but not fixed.** 42 consecutive passes with zero
  reproduction; two mechanisms (synthetic causality, lease leakage) excluded by
  construction and pinned by test. See `harness-d4-04-investigation.md`.

Running an ablation now would still produce a confident number that answers a
narrower question than the PRD asks — exactly the failure mode §7 validity rules
exist to prevent.
