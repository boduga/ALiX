## Findings carried out of collection

These are recorded as cohort evidence. None is to be fixed inside the cohort.

1. **Verification requirement detection is silent (0/8)** while
   `requirement:mutation` (7/8) and `requirement:coordination` (7/8) fire.
   Verification-shaped prompts produce no requirement candidates at all.
2. **`verify.claim` and `shell.run` are absent from the read-only offer set**, so
   `v1`/`v2` ("run X and report") were answered by reading rather than executing.
3. **Coordination completion is not verification.** All 7 runs closed
   `status: completed`, but only 3 carry an aggregate outcome; **4 of 7 closed
   with `outcome: null`** and no `aggregateResultRef`.
   `coordination.run` success ≠ aggregate outcome present ≠ session verified.
4. **The MCP/external family produced zero scopes**, by two distinct mechanisms:
   - `alix_mcp_search_tools` is short-circuited before `handleToolResult`
     (`src/execution/run/task-loop/main.ts:1341`), so a session that only calls that
     sentinel emits no selection observation (`x1`, ended `max_iterations`);
   - `x2`–`x8` ran single-tool external turns (≈15-event traces with one
     `tool.requested/completed` and no `model.usage`/`agent.decision`/
     `context.assembled`) that never entered the loop where observations are
     emitted.
   The family is therefore unrepresented in selection statistics.
5. **Jev re-scoring is not idempotent** (19/32 → 18/32 across rebuilds). Any
   report must cite the frozen corpus hash, not a re-derivation.
6. **No-op mutation is unobservable.** `changed` appears in 0 of 8 mutation
   traces and `file.updated` is never emitted, so `changed=false` cannot be
   counted without new instrumentation.
7. **Pattern/iteration accounting differs across emitters** —
   `context.pattern_evaluated.iterations` (2) vs
   `session.ended.contextPressure.totalIterations` (5) in the same run
   (`efe7959c`), with `agent.decision` recording iterations 0, 1, 3.
8. **The deterministic scoper is not task-conditioned** — it ranked
   `alix_create_hook` (9) and `alix_verify_claim` (8) above `alix_file_read` (6)
   for a read-and-summarize prompt, and scored English connectives as symbol
   matches at the same weight as real symbols. Diagnostic only; never a T3
   quality statistic.
9. **`done` is approval-gated interactively but auto-allowed headless**
   (`policy-gate.ts:493`), which cost one out-of-cohort session 300 s of idle
   approval wait plus a spurious `client_error_echo` completion rejection.
