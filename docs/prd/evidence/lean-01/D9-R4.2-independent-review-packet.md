## Required adversarial assessment

Review pending, denied, expired, cancelled, consumed-with-pending-outcome, unverified, failed, missing-outcome and projection-only states. Check host kind, run/session, worker ID and attempt, agent identity, tool/capability, args hash, workspace, ownership claim/scope, lease conflict, concurrent resumers and shutdown. Check a successful receipt committed before worker update: worker may be requeued only after verifying the committed record and original binding under the run lock.

Inspect the three crash windows separately: **before consumption**, **after consumption before effect**, and **after effect before outcome receipt**. Distinguish ledger durability, filesystem durability and actual daemon/worker process restart. A successful consumed claim is not a successful effect receipt. A sentinel file surviving SIGKILL is not a general transaction guarantee.
