# GE-04 SUP-25 — Atomic *inert* authorization fixture

**SECURITY HOLD: experimental cooperative state machine only. No authorization or production mutation.**

`experiments/ge04/sup25-atomic-authority-fixture.py` demonstrates one cross-process `flock` critical section covering reads of a single fixture-controlled approval, policy revision, lease ID, expiry, revocation flag, and durable attempt-consumption state. It stores state in a 0700 owner-only test directory via an O_NOFOLLOW, O_EXCL temporary file, `fsync`, rename, and directory `fsync`. Approval starts as approved and is consumed **once**, before the inert transition. Every later attempt, including a new attempt ID, is denied. The return marker is `SUP25_INERT_OUTCOME_UNVERIFIED`; there is no actual filesystem effect and no terminal authorization receipt.

`test-sup25-atomic-authority.py` exercises bad approval/lease/policy/expiry denial, replay denial, revocation-before-transition denial, revocation waiting for a concurrent locked transition, racing duplicate consumers, and crash after durable prepare. A crash leaves an in-flight attempt and consumed approval. No retry is considered safe. All legitimate outcomes remain UNVERIFIED or UNCERTAIN in the absence of durable final-effect evidence.

**Limitations:** All participants must voluntarily use the same lock and fixture file. A malicious coordinator or actor with write permission to the fixture directory can bypass or forge state; this is not an independent trust root. No supervisor owns the fixture state, no cryptographic approver identity is established, no real operation occurs, no atomic OS-mediated action gate exists, no multi-lease lifecycle, no authenticated terminal receipts, no replay protection across arbitrary provisioner resets, and no recovery classification for a real committed effect. The code must not be connected to `UnavailableScopedMutationService`. SUP-23's root subprocess is also not independent of its root launcher. PR #1039 stays open/unmerged pending independent security review and the remaining GE-04 work.
