# GE-04 SUP-26 — Inert terminal observation and fail-closed recovery

**SECURITY HOLD: experimental fixture only. A matching record is not an authenticated real mutation receipt.**

`experiments/ge04/sup26-inert-terminal-evidence.py` persists one create-once (`O_EXCL`/`O_NOFOLLOW`, `fsync` file and directory) JSON observation after a successfully returned SUP-25 **inert** transition. The record binds attempt ID, SHA-256 digest of the current SUP-25 state, and fixed `INERT_TRANSITION_OBSERVED_UNVERIFIED` marker with an HMAC under the SUP-15 fixture key. Reconciliation reopens and verifies the record and fixture state. It returns only `INERT_RECORD_MATCHED_EFFECT_UNVERIFIED` or `UNCERTAIN`, never operation success. Absence, malformed state, duplicates, unexpected attempt, missing key, tampering, and interrupted in-flight state fail closed.

`experiments/ge04/test-sup26-inert-terminal-evidence.py` tests record creation after inert completion, duplicate creation rejection, wrong attempt, tampered record, crash immediately after durable prepare, denial of attempts after crash and revocation, and recovery with no record. The CI gate is run with the rest of GE-04's experimental tests. The test does **not** exercise real power-loss durability or real committed effects.

**Remaining barriers:** The coordinator/test harness can create and read the fixture key and mutate the same-UID file tree; therefore the MAC is not an independently authenticated supervisor signature. There is no externally established trust root, trusted time, atomicity with an actual effect, independent process custody, key rotation, authenticated terminal effect receipt, or power-loss and filesystem corruption qualification. Even a valid inert marker only proves test fixture state consistency, not that a mutation occurred. No production mutation service is connected, and it is unsafe to retry ambiguous real effects. SUP-23's root subprocess also remains controlled by its root launcher. PR #1039 stays unmerged until independent security review and all production gates are satisfied.
