# GE-04 — Privileged endpoint hijack and stale recovery regression

**SECURITY HOLD continues. Experimental inert Linux fixture; no production authority.**

The root-only `test-isolated-endpoint-recovery-root.py` verifies the distinct-UID boundary added after SUP-27 when an endpoint exists before supervisor startup, during a permitted inert request, and after supervisor exit. A root-owned `0711` public socket directory is accessible for path traversal but not writable by UID 65534. The test drops an independently executed child to UID/GID 65534, then checks that it cannot unlink or chmod the root-owned socket, chmod the public directory, bind an alternate socket into it, or rewrite protected supervisor state.

An already-existing socket prevents the root supervisor from starting: startup must not unlink a potential orphan, live socket, or substituted endpoint. After explicit **privileged test-only** removal of the preexisting stale socket, the supervisor starts and accepts one fixed kernel-attested inert datagram. On exit the endpoint remains an orphan, and a subsequent launch fails closed rather than resetting state or silently overwriting the path. Approval stays consumed and cannot be replayed by restarting the fixture.

The fixture uses an intentionally world-sendable 0666 socket under a protected directory to permit its known UID test client; production policy must be separately designed. The privileged CI regression is required for this test; local syntax validation alone is insufficient. No production mutation path is enabled, and PR #1039 remains unmerged.
