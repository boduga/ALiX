# DOX — Benchmark harness history vs summary vs state vs hybrid

**Purpose:** Deterministic maintenance/reconciliation task harness proving the architecture (bounded state + hybrid retrieval vs history/summary baselines). C vs D primary bake-off, A/B baselines.

**Ownership:**
- `benchmark/evidence/cost/summarize-readonly-navigation.mjs` — offline arithmetic replay from committed raw results and explicitly supplied historical rate metadata. It does not requalify invocation-time pricing or oracle outcomes; default output is stdout and explicit file output refuses overwrite.
- `benchmark/evidence/gate7/baseline-coverage-matrix.mjs` — recorded artifact coverage, not Gate B acceptance or ablation authorization. Keep corpus validity and source-provenance limits visible beside legacy admission counts.
- `benchmark/evidence/cost/positive-cases.mjs` and `benchmark/evidence/cost/run-positive-cases.mjs` — isolated positive two-file and mixed-policy runtime fixtures. Default real runs resolve current `models.default`; `--scripted` validates mechanics only. Approval decisions are fixture-scoped to the exact output invocation; all recorded costs remain unknown until catalog-priced qualification.
- `benchmark/evidence/cost/eval-case-sweep.mjs` — per-case real-provider sweep for the behavioral strata. Resolves the operator's current `models.default` unless an explicit `--provider`/`--model` one-off is given, prices each case from `defaultPricingCatalog()`, and reports a verified success only when the oracle verified the claimed objective. Rows also carry `finishedAt`/`durationMs`, dispatched/rejected/repeat/tool-retry/approval/abort counts captured before the case cwd is deleted, and the payload carries per-case `latency` (p50/p95) separate from whole-suite wall time. Unobserved counts stay `null` with an `unobserved` reason; provider retries, driver re-invocations and operator active review minutes are not emitted anywhere per case and are never inferred.
- Behavioral sweep rows retain configured positive guard evidence; a missing or unsatisfied required guard cannot count as a verified success. Historical rows without guard evidence retain their original qualification limits.
- `benchmark/evidence/eval-runs/guarded-2026-10-23.json` retains scripted corpus outcomes, guard traces and exact source-file hashes. It qualifies mechanics only; billable usage, model quality and independent clearance remain unmeasured.
- `benchmark/evidence/coordination/run-restart-metered.mjs` — stratum-8 crash/restart harness: kills the process on a persisted running worker, resumes through the reclaim path, and records the crash-integrity fields, the final run state and the observed usage. Wipes its workspace on every run, so a deliverable left by an earlier run cannot satisfy the oracle.
- `benchmark/evidence/config-consumer-inventory.mjs` — compiler-backed static census of source references to config fields. Its JSON snapshot is review evidence only; dynamic keys, unresolved accesses, external packages, and graph coverage remain explicit limits.
- `benchmark/evidence/review-trial.mjs` — offline scoring and aggregation for human review observations. Public fixtures are training examples; they are not holdouts or human trial evidence.
- `benchmark/evidence/coordination/four-worker-scripted.mjs` — deterministic worker-executor fixture through the real coordination kernel. It measures scripted mechanics only; it is not model-quality, security, or paid-provider evidence. `four-worker-scripted.json` is its retained snapshot: point-in-time run ids, not reproducible ones.
- `benchmark/evidence/harness2-reproduction.json` — retained credential-free Harness² reproduction record. Reuse of a pre-existing environment does not qualify a fresh install.
- `types.ts` — Substrate (A_full_history/B_summary_fixed/C_state/D_hybrid), DecisionCategory (state-complete/evidence-dependent/history-dependent), BenchmarkScenario/Event/DecisionPoint, BenchmarkResultRow (machine-readable {scenario, seed, horizon, substrate, taskSuccess, decisionAccuracy, prompt/state/evidence/historyTokens, escalations, retrieval_precision, state_sufficiency}), BenchmarkReport/Summary, GovernanceConfig, REQUIRED_HORIZONS 10/50/100/500.
- `scenario.ts` — createScenario(seed, horizon) deterministic mulberry32 maintenance/reconciliation generator: execution.created + state-affecting + distractors + evidence.observation + history.artifact_detail, decision points cycling 3 categories every 10 steps, controlled failures/distractors, sorted seq invariant.
- `fake-environment.ts` — FakeExecutionEnvironment deterministic tools: getFullHistory, getLatestObservation, getEvidenceById/Slice, getSummaryFixed (fixed-budget lossy), getProjectedStateView (bounded state view, no evidence/history leak), toolReconcileCheck.
- `fake-model.ts` — FakeModel deterministic (tests substrate not model): correct iff required info present per category — state-complete needs state/summary/history, evidence-dependent needs evidence/history, history-dependent needs slice/history; summary lossy on evidence/history.
- `substrates.ts` — assembleContext(substrate, env, point, {includeEvidence, includeHistory}) token accounting (state/evidence/history/promptTokens via estimateTokens ~char/4): A history+obs O(T), B summary bounded lossy, C state+obs bounded, D hybrid state+targeted slice bounded.
- `tokens.ts` — estimateTokens deterministically (JSON length /4).
- `metrics.ts` — MetricsCollector 4-group metrics: correctness (taskSuccess, decisionAccuracy), context efficiency (prompt/state/evidence/historyTokens, cumulativeTokens), adaptive (escalations, unnecessary_escalations, retrieval_precision, historical_retrieval_rate, state_sufficiency), horizon (tokensPerStep, boundedness invariants).
- `harness.ts` — runSingle (same scenario/seed/governance for one substrate) + runHorizons (all horizons×substrates) + BenchmarkSummary invariants (cStateTokensBounded, cStateCompleteInvariant, dRecovers, dBounded, dPrecisionOk); D escalates deterministically only when required (evidence/history-dependent).
- `mutation-conflict.ts` — Mutation-conflict benchmark: deterministic N concurrent mutating calls sharing baseStateVersion V, scheduler eligible but CAS decides; StateTransitionProposal → ExecutionStateStore CAS → EventLog → projector proof (one success + N-1 STATE_VERSION_CONFLICT, no partial mutation, rebuilt state == committed, scheduler did not decide winner); supports N=2 and N>2.
- `real-eventlog-environment.ts` — RealEventLogEnvironment: replaces FakeExecutionEnvironment boundaries with real EventLog file `.alix/sessions/<id>/events.jsonl` + ExecutionStateStore `.alix/executions/<id>/state.json` + StateProjector (`project`/`toExecutionState`), ContextBuilder (`buildExecutionContext`), Governor→StepExecutor→EventLog loop; delegates evidence/history retrieval to `src/runtime-state/runtime/context/retrieval.ts` `ContextRetrieval` production indexes (by executionId/evidenceId/historySlice + checkpoint) with file-authoritative mtime-guarded cache, not `FakeExecutionEnvironment.getEvidenceById` stub; EventLog authoritative, state disposable, reuses `src/runtime-state/runtime/execution-state/*` + `src/runtime-state/runtime/context/retrieval.ts` (no new abstraction).
- `real-harness.ts` — runSingleReal/runHorizonsReal: same scenario/seed/governance as fake harness but ExecutionState sourced from real Store (file-backed) and D hybrid targeted fetch via `ContextRetrieval` real file indexes; proves C vs D horizon-invariant 10→500 bounded with real store, D recovers, precision 1.0 via real indexes.
- `mutation-conflict-stress.ts` — Concurrency stress N=5 mutating: extends `mutation-conflict.ts` base — N=5 concurrent mutating calls sharing baseStateVersion 17 but only one commits via CAS → v18; reuses StateTransitionProposal → ExecutionStateStore (CAS) → EventLog → projector chain; scheduler maxParallel:4 chunking respected under load (5→4+1, maxConcurrent==4, never 5), overlapping A.start<B.end proven within first batch, EventLog authoritative rebuilt==committed, schedulerDidNotDecideWinner; deterministic multi-seed stress, no LLM/no I/O.
- `session-shadow.ts` — Real-session shadow measurement: `mapSessionEventsToProjectorHistory(events, {executionId, objective})` maps live session events to the projector vocabulary. When the session already carries real `execution.*` events (opt-in `ExecutionStateEmitter`), those are forwarded verbatim; otherwise it synthesizes a candidate bridge (synthetic `execution.created` + `running` seeds; `tool.requested`→`execution.action_proposed`, `tool.completed`/`tool.failed`→`execution.action_completed`, `artifact.created`→`execution.artifact_registered`, `session.ended`→`execution.status_changed completed`; all other event types ignored). `measureSessionShadow(sessionDir, opts?)` is read-only (EventLog read, never appended) and compares the bounded `buildExecutionContext` prompt against the session's live `context.assembled` admittedTokens.
- `universal-row.ts` — Cross-harness universal row: one schema (`source/scenario|subject/seed/horizon/substrate/model/accuracy/tokens/escalations/precision`) for synthetic, real-model, and live-session rows. `toUniversalRows` is the harness emission point; `measureSessionShadow` attaches its row; `compareUniversalRows` (boundedness + optional accuracy delta), `checkUniversalInvariants` (horizon sweep), `assertLiveSendBar` (parity ±2pp process gate), and `renderUniversalTable` complete the one-table goal.
- `real-model-harness.ts` — Real-model accuracy eval (C vs D, optional Phi-3 Q4 / OpenRouter). Its single-run function assembles the substrate context, asks the provider a verbatim-extraction question per decision point, scores exact `includes(expected)`. `maxOutputTokens` is 2048; increase only with output-truncation evidence. Retries once at `temperature: 1` when a model rejects `temperature: 0` (gpt-5 family) and falls back to `reasoning` when `text` is empty. Accuracies reflect model usability, not substrate perfection. CLI `main()` runs smoke horizon 10, or `--full` 10/50/100/500. OpenRouter runs consume account credits — a 402 means the balance cannot cover the requested `max_tokens`, not a model failure.

**Local Contracts:**
- Positive/restart evidence runs may use an explicit `--output-cap N` override, validated before workspace mutation and recorded with results. It affects temporary workspace configuration only; omission preserves configured behavior. A successful small probe does not prove full runtime quota availability. Restart fault injection may wait for persisted running-worker state; its final session-log snapshot already contains pre-kill usage and must be counted once.
- Cost qualification requires an explicit positive integer `verifiedSuccesses` alongside complete, finite, stratum-attributed cost. Missing/null counts remain unknown; evaluator passes whose oracle did not verify the claimed objective cannot be backfilled as verified successes. Keep raw paid usage even when qualification fails.
- Same scenario/seed/environment/governance/budget for A/B/C/D — comparable rows.
- C horizon-invariant on state-complete (accuracy 1.0, tokens bounded 10→500), D recovers evidence/history-dependent where C fails.
- D context bounded, retrieves only when required — retrieval_precision, unnecessary_escalations measured.
- FakeModel isolates substrate — correctness reflects state adequacy, not intelligence.
- `session-shadow.ts` and `real-model-harness.ts` measure **model usability**, not substrate perfection: whether a real model can find/copy what's in the assembled context. They cannot prove task success, and thinking-model output budgets / credit-limited samples can understate accuracy. FakeModel remains the substrate ceiling; real-model runs are the usability gate.
- Synthetic and file-backed substrate harnesses are deterministic, fail-closed, and use no LLM. `real-model-harness.ts` explicitly invokes providers. Authoritative EventLog history is immutable; projected state is disposable. File-backed harnesses use temporary directories and atomic EventLog/Store writes; session shadow reads existing EventLogs without appending.
- Do NOT touch contract/store/projector/prompt/governor — only harness; real integration reuses `src/runtime-state/runtime/execution-state/*` and `src/runtime-state/runtime/state/*` + `src/runtime-state/events/event-log.ts` + `src/runtime-state/runtime/context/*` without new abstraction.

**Work Guidance:**
- Keep production contracts unchanged when extending benchmark scenarios; reuse existing stores, projectors, context builders, governors, and executors.
- Keep real-provider measurements separate from deterministic substrate results and report truncation or credit-limited samples.
